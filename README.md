# BlockDAG Payments Gateway for WooCommerce

**Unofficial grant prototype – BlockDAG Grants Program**

This repository contains the documentation and roadmap for a Web3 payment gateway
that enables **BDAG token payments in WooCommerce**, designed as a non-commercial
prototype for the BlockDAG ecosystem.

---

## 🚀 Project Overview

The goal of this project is to demonstrate **real-world utility of the BDAG token**
in eCommerce by integrating native Web3 payments into WooCommerce – one of the most
widely used eCommerce platforms globally.

The plugin allows merchants to accept BDAG payments directly via EVM-compatible
wallets (such as MetaMask or WalletConnect), without intermediaries, custodians
or traditional payment processors.

---

## 🎯 Key Objectives

- Enable native BDAG payments in WooCommerce stores
- Lower adoption barriers for Web2 merchants entering Web3
- Provide a real checkout flow using BlockDAG testnet
- Deliver an open-source reference implementation for the ecosystem

---

## ✨ Key Features (Planned)

- BDAG payment method integrated into WooCommerce checkout
- Wallet-based payments (MetaMask / WalletConnect)
- Automatic order status updates after on-chain confirmation
- Transaction hash storage inside WooCommerce orders
- Support for BlockDAG EVM-compatible testnet (Awakening)
- Simple admin configuration (merchant wallet address & network)

---

## 🧱 Technical Architecture

### Backend
- WordPress / WooCommerce (PHP)
- Custom WooCommerce payment gateway
- AJAX endpoints for transaction verification
- Native WooCommerce order lifecycle integration

### Frontend
- JavaScript Web3 integration
- EVM wallet connection (MetaMask / WalletConnect)
- User-friendly Web3 checkout flow
- Transaction status feedback for users

### Blockchain
- BlockDAG EVM-compatible network
- Native BDAG transfers
- No smart contracts required for MVP
